# Z35T

Library for JS work on-the-go

## Import

Observable notebook, or any browser ESM import:

```js
z35t = import("https://cdn.jsdelivr.net/gh/zachbogart/z35t@main/src/index.js")
z35t.version
```

Pin to a tagged version instead of `@main` for stability: `@v0.1.0`.

Node / bundler:

```js
import * as z35t from "z35t";

z35t.version;
```
