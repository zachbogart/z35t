    z35t

    z35t

    Personal JS utility library. Plain ESM, no build step, import anywhere.

    Use in Observable notebook

    Once pushed to GitHub (works immediately, no npm publish needed):

    z4 = import("https://cdn.jsdelivr.net/gh/USER/REPO@main/index.js")
    z4.hello("Observable")

    After publishing to npm:

    z4 = import("https://cdn.jsdelivr.net/npm/z35t@1/+esm")

    Use in Node / browser

    import { hello, version } from "z35t";

    hello("world"); // "Hello, world!"

    Add functions

    Edit index.js, export new functions. Keep each function pure and standalone so it works well when imported piecemeal in a notebook cell.

    Docs (auto-generated, searchable)

    Docs are generated straight from JSDoc comments on your exports — no separate docs to write or keep in sync. Regenerate after adding/changing functions:

    npm run docs

    Outputs a static, searchable HTML site to docs/. Commit it and enable GitHub Pages (Settings → Pages → Source: main branch, /docs folder) to publish it online.

    Publish to npm

    npm publish
